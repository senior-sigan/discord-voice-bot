# Веб-исследование

1. Сформулируй точный запрос и вызови `web_search`.
2. Если сниппетов недостаточно, прочитай наиболее подходящую страницу через `web_fetch`.
3. Для спорного или важного утверждения проверь первичный источник либо второй независимый источник.
4. Отвечай только на основании найденного. Если данные расходятся или недоступны, честно обозначь неопределённость.

Не вызывай веб-поиск, если ответ уже есть в контексте и не зависит от текущего времени.
